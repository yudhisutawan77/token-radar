# Token Radar

A token launch radar for make.fun's **Build the best token launch radar** bounty
(`token-radar-01`, $1,325 in escrow, 10 places paid).

It reads a sealed DefiLlama snapshot of 758 protocols, finds the ones that
record no token and are not a wrapped, staked or bridged product of one that
trades, ranks them by an implied value priced off the live market, and hands
in a dashboard a reader can use: a board, a detail view for every protocol,
and a filter — each row carrying a farm plan and a farm verdict netted to
the dollar, and the model itself tested out of sample before it is trusted.

## What is in here

- `main.ts` — the entrypoint (Node 22, standard library only). Reads the
  snapshot, scores the board, writes `board.json`, `data.js`, `dossier.json`
  and copies `dashboard/` and `screenshots/` to the output directory.
- `lib/model.ts` — the radar-4 model, the only place the ranking is computed.
- `lib/validation.ts` — the out-of-sample tests: leave-one-out, time-split,
  bootstrap of the top 10.
- `dashboard/` — the static page (no network, no framework): `index.html`,
  `app.css`, `app.js`. `main.ts` also writes `dashboard/validation.json`
  beside the page, so the dossier's text carries the validation numbers.
- `vendor/makefun-board.ts` — make.fun's dossier library, copied verbatim.
- `screenshots/` — the three screenshots: the board, a protocol detail, a
  filtered view.
- `board.json`, `dossier.json` — generated by running `main.ts` (see below);
  the checked-in copies are the ones the last run wrote.

## The model (radar-4)

Implied value is anchored in the snapshot's own live market, not in a
hand-picked multiple:

```
implied = round(exp(a + b x ln TVL + offset) x growth x maturity x 0.85)
```

- **Size curve** — a log-log fit of market cap on TVL over the 109
  live-token protocols whose market-cap / TVL ratio lies between 0.02 and
  20: ln(market cap) = 4.568 + 0.676 x ln(TVL). Each category gets an
  offset — the mean residual of its live protocols, shrunk toward zero
  with 8 pseudo-observations. A protocol's fitted multiple is the curve's
  prediction at its own TVL, clamped to 0.08x–1.20x. Size itself predicts
  the multiple: larger protocols trade at lower multiples, and the fit
  says so (slope 0.68, well under 1).
- **Growth** — the 7-day TVL change, clamped to −50%…+100%, moves the value
  by 0.6x the change.
- **Maturity** — 0.70 + 0.30 × min(age, 1095) / 1095, where age is the time
  since first listing (365 days when unlisted).
- **Pre-token discount** — 0.85, because a token that does not exist yet
  cannot be sold today.

Coverage: the 40-protocol watchlist is always covered, plus every other
pre-token protocol that passes the same launch screen the watchlist uses
(not a CEX, bridge, liquid staking/restaking or restaked BTC product; not
a versioned pool; not a wrapped/staked product; not an exchange's own
product) — 158 early rows, 198 rows in all, 20 of them above the $50M
floor. The board ranks what the live market would pay, not the watchlist's
cutoff. 144 pre-token protocols are screened out, and the dashboard names
why.

Every row's farm plan has seven steps, each with a cost and a time, derived
from the protocol's own category, chain, TVL and age. No token is promised:
the plan farms usage history, and the detail view says so in plain words.
Every row also carries a farm verdict, netted to the dollar: the plan's
gas, the farmer's time at $25 an hour, and the carry on the locked capital
at 5% a year, totalled against the expected payout — the implied value at
the band's low end (the multiple at its 0.08x floor) times a stated
farmer's share of 0.0025% (5% of supply to about 2,000 qualifying
wallets). FARM clears a $50 low-end net, THIN covers its cost, SKIP does
not. The share is a stated assumption, not a fact; the verdict is a cost
screen, not a promise of a payout.

The curve is tested out of sample before the board is trusted
(`lib/validation.ts`, and the numbers in the dashboard and the dossier):
leave-one-out over the 109 live comparables, median error multiple x2.91;
a time-split fitted on listings before 2024-02-06 and tested on 41 newer
ones, median error x2.64; a 200-round bootstrap in which the top 10 keeps
8.87 of its 10 rows on average, each top-10 row moving 0.76 ranks. The
curve is a pricing kernel, not a price: the median protocol is mispriced
by a factor of three.

The dashboard recomputes every row's implied value from the row's own
multipliers and checks it against `board.json`, so the page and the board
cannot disagree.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input token-radar-01-kit/input/snapshot.json
```

Then open `out/dashboard/index.html` in a browser (it renders with no
network). The three screenshots are taken with headless Chromium:

```sh
node dev/shoot.mjs out
```

Check the output against the gate's seven rows:

```sh
node dev/check-gate.mjs out
```

## Results (snapshot 2026-11-14)

- 198 rows: 40 watchlist + 158 early (20 above the floor); 144 pre-token
  protocols screened out.
- Top of the board: Steakhouse Financial, $201,792,375 implied, then
  Sentora Curator ($198,459,115) and Gauntlet ($145,064,241). The curve
  prices the largest protocols lower than the old median-ratio model did
  ($1.19B for the same top row), because the fit says large TVL trades at
  a lower multiple — the top five names and their order are unchanged.
- Farm verdicts: 39 FARM, 19 THIN, 140 SKIP, netted at the band's low end.
- Validation: LOOCV median error x2.91, time-split x2.64, bootstrap top 10
  keeps 8.87 of 10 rows.
- Gate: all 7 rows pass locally; two runs write byte-identical output.
- Dashboard source: 36,660 bytes, so the dossier carries it whole.

## Honesty notes

- "Records no token" is what the snapshot says; it is not proof a protocol
  has none.
- An implied value is the model's claim, never a price and never a
  prediction that a token will be issued, or when.
- Farm plans are suggestions, not financial advice. Never pay anyone to
  claim an airdrop.
