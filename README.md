# Token Radar

A token launch radar for make.fun's **Build the best token launch radar** bounty
(`token-radar-01`, $1,325 in escrow, 10 places paid).

It reads a sealed DefiLlama snapshot of 758 protocols, finds the ones that
record no token and are not a wrapped, staked or bridged product of one that
trades, ranks them by an implied value priced off the live market, and hands
in a dashboard a reader can use: a board, a detail view for every protocol,
and a filter — each row carrying a farm plan.

## What is in here

- `main.ts` — the entrypoint (Node 22, standard library only). Reads the
  snapshot, scores the board, writes `board.json`, `data.js`, `dossier.json`
  and copies `dashboard/` and `screenshots/` to the output directory.
- `lib/model.ts` — the radar-2 model, the only place the ranking is computed.
- `dashboard/` — the static page (no network, no framework): `index.html`,
  `app.css`, `app.js`.
- `vendor/makefun-board.ts` — make.fun's dossier library, copied verbatim.
- `screenshots/` — the three screenshots: the board, a protocol detail, a
  filtered view.
- `board.json`, `dossier.json` — generated by running `main.ts` (see below);
  the checked-in copies are the ones the last run wrote.

## The model (radar-2)

Implied value is anchored in the snapshot's own live market, not in a
hand-picked multiple:

```
implied = round(TVL x category multiple x growth x maturity x 0.85)
```

- **Category multiple** — for each category, the median market-cap / TVL of
  the protocols in it that already trade (ratios outside 0.02–20 are dropped),
  shrunk toward the global median (0.310x) with 8 pseudo-observations, and
  clamped to 0.08x–1.20x. A category with one live protocol does not inherit
  its multiple wholesale.
- **Growth** — the 7-day TVL change, clamped to −50%…+100%, moves the value
  by 0.6x the change.
- **Maturity** — 0.70 + 0.30 × min(age, 1095) / 1095, where age is the time
  since first listing (365 days when unlisted).
- **Pre-token discount** — 0.85, because a token that does not exist yet
  cannot be sold today.

Coverage: the 40-protocol watchlist is always covered, plus every other
pre-token protocol below the $50M floor that passes the same launch screen
the watchlist uses (not a CEX, bridge, liquid staking/restaking or restaked
BTC product; not a versioned pool; not a wrapped/staked product; not an
exchange's own product) — 138 early rows, 178 rows in all. 164 pre-token
protocols are screened out, and the dashboard names why. Protocols the
watchlist leaves out above the floor are not ranked: the house's rule had a
reason for them (a parent protocol in DefiLlama's record, which the snapshot
does not carry), so the radar does not second-guess it.

Every row's farm plan has seven steps, each with a cost and a time, derived
from the protocol's own category, chain, TVL and age. No token is promised:
the plan farms usage history, and the detail view says so in plain words.

The dashboard recomputes every row's implied value from the row's own
multipliers and checks it against `board.json`, so the page and the board
cannot disagree.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input token-radar-01-kit/input/snapshot.json
```

Then open `out/dashboard/index.html` in a browser (it renders with no
network). The three screenshots are taken with headless Chromium:

```sh
node dev/shoot.mjs out
```

Check the output against the gate's seven rows:

```sh
node dev/check-gate.mjs out
```

## Results (snapshot 2026-11-14)

- 178 rows: 40 watchlist + 138 early; 164 pre-token protocols screened out.
- Top of the board: Steakhouse Financial, $1,188,413,256 implied, then
  Gauntlet ($713,257,788) and Veda ($341,850,641).
- Gate: all 7 rows pass locally; two runs write byte-identical output.
- Dashboard source: 28,697 bytes, so the dossier carries it whole.

## Honesty notes

- "Records no token" is what the snapshot says; it is not proof a protocol
  has none.
- An implied value is the model's claim, never a price and never a
  prediction that a token will be issued, or when.
- Farm plans are suggestions, not financial advice. Never pay anyone to
  claim an airdrop.
